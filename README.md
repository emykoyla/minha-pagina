## 📌 Sobre o projeto

O **Minha Lâmpada** é um projeto desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento web.

A página apresenta uma lâmpada que pode ser ligada e desligada através de um botão. A interação é controlada por JavaScript, utilizando eventos de clique, manipulação de classes CSS e estruturas condicionais `if/else`.

O projeto possui uma interface simples, intuitiva e responsiva, proporcionando uma experiência agradável ao usuário.

## ⚙️ Funcionalidades

- 💡 Acender a lâmpada através de um botão.
- 🌑 Apagar a lâmpada com um novo clique.
- 🔄 Alternar automaticamente entre os estados.
- 📝 Atualizar o texto de status conforme a situação da lâmpada.
- ✨ Aplicar efeitos visuais quando a lâmpada está acesa.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes de programação:
